# Droply Launcher — atualizações

Este repositório é usado **somente** para distribuir as atualizações do Droply Launcher.
Não contém o código-fonte do aplicativo.

- **Baixar / instalar:** abra a aba [Releases](../../releases) e baixe `DroplyLauncher-Setup-<versão>.exe` (instalador) ou `DroplyLauncher-Portable-<versão>.exe` (portátil).
- **Atualizar:** quem já tem o Droply instalado não precisa vir aqui; o próprio aplicativo avisa quando há versão nova (Configurações → Atualizações do Droply).
- Cada Release traz também `latest.yml` e `*.blockmap`, usados pelo atualizador para conferir o arquivo (SHA-512). Não são para uso manual.
